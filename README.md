# Портфолио Екатерины Дорошенко

Статический сайт-портфолио (перенос с Тильды). Без сборки: обычные HTML/CSS/JS.

## Структура

```
index.html            — главная: первый экран, проекты, галерея
projects/*.html       — страницы кейсов
css/style.css         — все стили
js/main.js            — лайтбокс галереи
img/projects/         — обложки проектов на главной
img/cases/<проект>/   — картинки внутри кейсов
img/gallery/          — галерея работ (01–12)
video/hero.mp4        — видео на первом экране
```

## Как добавить / изменить проект

- **Текст кейса** — открыть `projects/<проект>.html` и поправить текст между тегами.
- **Картинка в кейсе** — положить файл в `img/cases/<проект>/` и вставить строку:
  `<figure class="case-img"><img src="../img/cases/<проект>/04.jpg" alt="Описание" loading="lazy"></figure>`
- **Карточка на главной** — блок `<a class="project-card" ...>` в `index.html`.

### НУА (заглушка)

`projects/nua.html` заполнен заглушками (жёлтые блоки с ✏️ и пунктирные рамки 🖼).
1. Положить картинки в `img/cases/nua/` (01.jpg — обложка и т.д.).
2. Заменить `<div class="img-placeholder">…</div>` на `<img src="../img/cases/nua/01.jpg" alt="…">`.
3. Заменить `<p class="todo">…</p>` на свой текст.
4. На главной заменить `<div class="cover-placeholder">НУА</div>` на `<img src="img/projects/nua.png" alt="Сайт для НУА">`
   и обновить описание карточки.

## Публикация на GitHub Pages

1. Создать репозиторий на github.com (например, `portfolio`) и загрузить в него содержимое этой папки.
2. Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)`.
3. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/portfolio/`.

### Свой домен ekaterinadoroshenko.ru

1. В Settings → Pages → Custom domain вписать `ekaterinadoroshenko.ru` (GitHub сам создаст файл `CNAME`).
2. У регистратора домена удалить записи, ведущие на Тильду, и добавить:
   - 4 записи `A` для `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - запись `CNAME` для `www` → `<логин>.github.io`
3. Подождать обновления DNS (от пары часов до суток), затем включить **Enforce HTTPS**.
4. После этого можно отключать сайт на Тильде.

## Локальный просмотр

```bash
python3 -m http.server 8000
```
и открыть http://localhost:8000
